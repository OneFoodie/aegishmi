# 界面演示启动步骤

演示形态：10 台模拟仪表（sim01~sim10）+ 上位机主界面，验证多设备连接、链路健康、波形与测试流程。

## 0. 前置条件

- 已构建：`build-mingw\bin\aegis_hmi.exe`、`aegis_sim.exe`、`aegis_linkcheck.exe` 存在
  （未构建时执行 `scripts\build.bat` 或 `cmake --build build-mingw -j 8`）。
- MinGW 构建需要 Qt 运行时在 PATH 中；若用 `dist\` 部署包（`scripts\deploy.bat` 生成）则无需设置。
- 端口 29527~29536 未被占用（可用 `netstat -ano | findstr 295` 检查）。

## 1. 启动 10 台模拟仪表（保持运行）

在 **PowerShell** 中执行：

```powershell
cd d:\project\traecode\prj2\aegishmi
$env:PATH = 'D:\Qt\Tools\mingw1310_64\bin;D:\Qt\6.8.3\mingw_64\bin;' + $env:PATH
pwsh scripts\sim10_connect_test.ps1 -KeepRunning
```

脚本会：

1. 按 `configs\devices\fleet_10sim.json` 的端口启动 10 个 `aegis_sim` 进程（仅自定义协议，
   Modbus/OPC UA/SCPI 端口置 0，避免冲突）；
2. 运行一次 `aegis_linkcheck` 预检，预期输出 10 行 `PASS` 与
   `summary: 10 link(s), 0 failed ... -> PASS`；
3. 因带 `-KeepRunning`，模拟器保持运行并打印 PID。

> 若预检失败，先按第 6 节排查，不要继续演示。

## 2. 启动上位机

另开一个 PowerShell（模拟器窗口保持不动）：

```powershell
cd d:\project\traecode\prj2\aegishmi
$env:PATH = 'D:\Qt\Tools\mingw1310_64\bin;D:\Qt\6.8.3\mingw_64\bin;' + $env:PATH
$env:AEGIS_FLEET_CONFIG = (Resolve-Path 'configs\devices\fleet_10sim.json').Path
.\build-mingw\bin\aegis_hmi.exe
```

使用部署包时：

```powershell
$env:AEGIS_FLEET_CONFIG = (Resolve-Path 'dist\configs\devices\fleet_10sim.json').Path
.\dist\aegis_hmi.exe
```

`AEGIS_FLEET_CONFIG` 只在上位机启动时读取，改了清单需要重启程序。

## 4. 界面演示路线

> 首次启动会自动弹出“快速上手”（5 步流程 + 功能地图 + 常见问题），
> 之后可随时点顶部状态条右侧的“使用说明”再次打开；界面上每个控件都有悬停提示。
> 顶部常驻状态条显示：链路在线数、未恢复报警（点击进报警页）、当前工单、登录用户。
> 页面切换使用左侧纵向导航（带图标与选中高亮），顶部显示当前页标题与一句话说明。

1. **监控页 · 设备与连接**
   - 右侧波形上方是设备 Faceplate：设备名、协议/地址、主/辅链路与连接状态。
   - 左侧按“① 选择设备并连接 → ② 查看数据与链路健康 → ③ 工具与诊断”分区，
     每段下方都有灰色操作提示。
   - “设备列表”显示 sim01~sim10；启动约 0.3 秒后按 `autoConnect` 自动连接。
   - “链路”下拉显示 `main`（一条链路一台设备）；点“连接/断开”可单独控制当前设备。
   - 状态用颜色胶囊显示（绿色=已连接），统计区显示采样率/帧数/CRC/丢块/接收量。
2. **链路健康面板**
   - 左侧“链路健康”表格每秒刷新：链路、协议、状态（在线绿色/离线红色）、最近入站延迟、帧数。
   - 断开某一台设备后，对应行应变为“离线”，其余设备不受影响。
3. **波形与操作**
   - 选中任一设备查看实时波形与通道阈值。
   - “报文诊断（HEX）”勾选后，运行日志显示收发报文（前 96 字节）。
   - “捕获波形…”开始捕获最近 20 秒，再次点击保存 CSV。
   - “日常点检”按 `active.json` 的金样值检查各通道。
4. **测试页**
   - 顶部提示条给出流程：① 加载方案 → ② 填写/扫描 SN → ③ 开始测试。
   - 选择测试方案 → “开始”：按步骤执行并写入结果；可查看判定、实测值、耗时；
     运行中可“停止”，“单步调试”用于逐步排查。
5. **其他页签**
   - 趋势：勾选多个通道（最多 4 条）做曲线对比，支持 5m/1h/8h/24h 快捷范围。
   - 报警：可“确认选中/全部确认”，也可对已知异常“搁置 10 分钟”（期间不产生新报警，已存在报警仍会恢复）。
   - 插件：展示外部插件的版本/能力/清单状态，可自检与打开插件目录（插件工程独立维护，见 `aegis-plugin-sdk`）。
   - 历史（按 SN/工单/方案检索、导出 PDF/CSV）、SPC、生产看板、班组、审计、用户管理。

## 5. 停止演示

关闭上位机窗口后，停止模拟器：

```powershell
Get-Process aegis_sim | Stop-Process -Force
```

## 6. 常见问题

| 现象 | 处理 |
|---|---|
| 启动上位机提示缺少 DLL | 未把 `D:\Qt\6.8.3\mingw_64\bin` 与 `D:\Qt\Tools\mingw1310_64\bin` 加入 PATH；或改用 `dist\` 部署包 |
| 端口监听失败 / 连接测试 FAIL | 端口被占用或模拟器未起来：`netstat -ano \| findstr 29527`，必要时结束占用进程后重跑第 1 步 |
| 设备列表不是 10 台 | `AEGIS_FLEET_CONFIG` 未设置或指向了旧清单；确认路径为 `configs\devices\fleet_10sim.json` 后重启 |
| 想看双链路演示 | 使用 `fleet.json`（dev1/dev2）或自建含 `links` 数组的清单，步骤为 3/4 的 6 通道模板 |
| 只看 2 台快速演示 | `scripts\demo_multi_device.bat`（需先 `scripts\deploy.bat` 生成 dist） |

## 7. 相关文件

- 清单：`configs\devices\fleet_10sim.json`（sim01~sim10，端口 29527~29536）
